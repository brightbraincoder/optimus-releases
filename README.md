# Optimus Releases

Binary releases for [Optimus](https://github.com/brightbraincoder/optimus-releases) — an agentic coding CLI by BrightBrainCoder.

## Install

- **Homebrew**: `brew install brightbraincoder/optimus/optimus-cli`
- **Scoop**: `scoop bucket add optimus https://github.com/brightbraincoder/optimus-releases` then `scoop install optimus/optimus-cli`
- **winget**: `winget install BrightBrainCoder.OptimusCli` (not yet available — coming soon)
- **AUR**: `yay -S optimus-cli-bin` (or your AUR helper of choice)
- **Manual**: download the binary for your platform from [Releases](https://github.com/brightbraincoder/optimus-releases/releases).

Whichever method you use, the installed command is `optimus`.
