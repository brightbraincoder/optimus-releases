# Optimus Releases

Binary releases for [Optimus](https://github.com/brightbraincoder/optimus-releases) — an agentic coding CLI by BrightBrainCoder.

## Install

- **Homebrew**: `brew install brightbraincoder/optimus/optimus`
- **Scoop**: `scoop bucket add optimus https://github.com/brightbraincoder/optimus-releases` then `scoop install optimus/optimus`
- **winget**: `winget install brightbraincoder.Optimus`
- **AUR**: `yay -S optimus-bin` (or your AUR helper of choice)
- **Manual**: download the binary for your platform from [Releases](https://github.com/brightbraincoder/optimus-releases/releases).
